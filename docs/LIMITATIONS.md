# Limits that stay visible

1. **Supplied structure:** dependencies, purposes, source labels, states and reviews are assertions. Missing relationships cannot be recovered by this tool.
2. **No semantic truth test:** a false successor or false rationale can be structurally consistent. The negative fixture demonstrates this.
3. **No authentication:** reviewer names, revisions and permission records are not signed or independently verified.
4. **No erasure:** exact originals and history remain. This is unsuitable as proof of deletion, privacy compliance or a secret-removal service.
5. **No enforcement:** generated context does not force an LLM to obey; an eligible record is not authorization to act.
6. **Conservative dependencies:** every hard dependency is required. Independent alternative support, causal confidence, time decay, automatic extraction and conflict resolution are not implemented.
7. **Guard text can conflict:** retaining all current constraints prevents silent loss under this contract but may overconstrain or contradict a task.
8. **No quality claim from counts:** synthetic regression results are not hallucination reduction, retrieval precision, independent evaluation or production reliability.
9. **No live integration:** no Windows project, Godot runtime, Wolfram runtime, model, database or vector store was exercised.
10. **File-system boundary:** bounded snapshots and exclusive creation do not protect against every concurrent mutation, hostile parent directory or interrupted write. Leaf symlinks are refused where the operating system exposes `O_NOFOLLOW`; Windows behavior was not tested. Parent directories must be trusted. Shell redirection can overwrite files before the program runs.
11. **Partial output:** interrupted creation can leave a partial new bundle. The manifest is written last, but its presence is not cryptographic authentication. Inspect hashes and command outcome.
12. **Privacy of reports:** IDs, relationships, fingerprints, reviewer labels and rationales may be sensitive. Projections/history include record text. No output is automatically anonymous or safe to upload.
13. **JSON identity:** structured fingerprints normalize object-key order and formatting, not Unicode or array order. They are not trusted timestamps or signatures.
14. **Bounds, not measured security:** input limits reduce accidental load; no formal security audit or denial-of-service benchmark was performed.
15. **No comprehensive novelty review:** selected relevant public sources were read. This is not a patentability, freedom-to-operate or exhaustive prior-art determination.
